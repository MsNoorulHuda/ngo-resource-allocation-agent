CHANGELOG.md

Version 1.0.0

Added

Natural-language question answering for NGO resource allocation data.

Automatic data cleaning and schema mapping.

Gap and shortage analysis.

Trend detection and worsening-shortage analysis.

Area and resource comparisons.

Pairwise comparison between areas.

Analyst Agent for performing data analysis.

Validator Agent for independently checking analytical results.

Grounded final answers based on dataset values.

Support for messy and differently named dataset columns.

Basic recommendations based on identified shortages.


Improved

Added deterministic validation to reduce incorrect AI-generated results.

Improved handling of missing or malformed analysis results.

Improved number and date formatting.

Added support for surplus and shortage distinction.

Improved handling of multiple allocation records.


Documentation

Added project installation instructions.

Added usage documentation.

Added architecture documentation.

Added contribution guidelines.

Added security guidelines.

Added project roadmap.


Known Limitations

The project currently runs mainly through the command line.

It does not yet provide a web-based dashboard.

Analysis depends on the quality and completeness of the provided dataset.

Real-time NGO data integration is not currently supported.
