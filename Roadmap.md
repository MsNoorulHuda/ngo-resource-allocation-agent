Project Roadmap

This project is currently a prototype for analyzing NGO resource allocation data using AI-assisted analysis and deterministic validation.

Completed

Natural-language questions about NGO resource allocation

Automatic data cleaning and schema mapping

Gap and shortage analysis

Trend and worsening-shortage detection

Area and resource comparisons

Multi-step analysis of complex questions

Analyst Agent for data analysis and answer generation

Validator Agent for checking analytical results

Grounded responses based on actual dataset values

Support for messy and differently named dataset columns


Planned Improvements

1. Web Interface

Develop a simple web interface where NGO staff can upload datasets and ask questions without using the command line.

2. Interactive Dashboard

Add charts and visualizations for:

Resource shortages

Surplus resources

Area-wise allocation

Trends over time

Resource comparisons


3. More Data Sources

Support additional CSV, Excel, and database sources so the system can work with different NGO record formats.

4. Advanced Recommendations

Improve the system to provide more useful recommendations, such as which areas or resources should be prioritized.

5. Automated Reports

Generate downloadable reports containing analysis, evidence, trends, and recommendations.

6. Real-Time Data

Future versions may support regularly updated or real-time NGO allocation data.

7. Improved AI Agents

Expand the agent architecture with more specialized agents for data quality, analysis, recommendations, and reporting while keeping validation deterministic.

Long-Term Goal

The long-term goal is to develop a reliable NGO resource-allocation assistant that can help organizations identify shortages, understand trends, compare resource distribution, and make better allocation decisions from their data.
