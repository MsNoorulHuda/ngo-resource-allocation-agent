SECURITY.md

Security
This project may use API keys and external AI services. Sensitive information must be kept private.

Reporting Security Issues
If you find a security vulnerability, report it to the project owner privately instead of posting it publicly.
Please include:
A description of the issue
Steps to reproduce it
Possible impact
Any relevant screenshots or logs

Security Guidelines

Never commit API keys or passwords.
Store secrets in .env files.
Do not upload sensitive NGO or personal data.
Keep dependencies updated.
Validate input data before processing.
