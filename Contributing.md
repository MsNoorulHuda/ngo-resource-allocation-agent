CONTRIBUTING.md

How to Contribute

1. Fork or clone the project.

2. Create a new branch for your changes.

3. Make and test your changes.

4. Keep code clear and follow the existing project structure.

5. Do not commit passwords, API keys, or other sensitive information.

6. Update documentation when necessary.

7. Submit a pull request with a clear description of your changes.

Testing

Run the test file before submitting changes:

python src/test_newdataset.py

Contributions should not break existing functionality.
